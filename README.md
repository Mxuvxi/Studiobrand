# Atelier de Marque
Outil en un seul fichier HTML (hors ligne) : à partir d'un logo, génère une charte graphique, puis transforme une photo en visuels prêts à publier (post, portrait, story, LinkedIn, bannière) avec 25 modèles.

- `atelier-de-marque.html` : l'outil complet, à ouvrir dans Chrome.
- `src/` : sources du moteur (données, texte, photo, logo, modèles, interface) et script d'assemblage.
